> ## This repository is deprecated and archived
>
> **`eido` is now part of [`peppy`](https://github.com/pepkit/peppy) as the `peppy.eido` module.**
>
> This repository is a public archive and is no longer maintained. All supported
> functionality has been merged into `peppy`. Please migrate:
>
> ```python
> # Before
> import eido
>
> # Now
> import peppy.eido
> ```
>
> Install `peppy` and use `peppy.eido` going forward — see the
> [peppy repository](https://github.com/pepkit/peppy) for details.
